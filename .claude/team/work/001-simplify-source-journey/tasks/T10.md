## Behaviour to implement (`crates/spectrum-driver-sa430/src/lib.rs`)
- `info()`: `transport: Transport::Usb` (badge reads USB); connection `port` ParamSpec help = `Path of the device's serial port, for example /dev/ttyACM0.`
  (keep `required: false`; the dialog treats it as required, plan section 5).
- `discover()`: `device_id` = USB serial (trimmed, non-empty) else `port:<name>`; if two scanned ports report the same serial, both get `port:<name>` ids. `label` unchanged
  (`SA430 <sn>` / `SA430 on <port>`), `location: Some(port name)`, details unchanged. Enumeration only, never opens.
- `open(config)`: resolve the port: `device_id` starting `port:` -> that name; `device_id` = serial -> scan, find the port with that serial, else the
  `connection.port` hint if non-empty, else `SourceError::unavailable("SA430 <serial> not found. Plug it in and check the cable.")`;
  no `device_id` -> typed port if non-empty, else the first discovered device (as today). Open it, read the calibration serial. If an expected serial (non-`port:`) was
  requested and the found one differs: `SourceError::unavailable("Expected SA430 <expected> but <port> is SA430 <found>. Open Edit source and test the connection to use this one, or choose the right port.")`.
  Return `OpenedSource { device_id: Some(<found serial> or "port:<port>" when the device reports none), connection: {"port": <port used>}, label as today, .. }`.
- `normalize_device_id(device_id, label)`: label `SA430 <serial>` (serial = remaining token, non-empty, no spaces) -> `Some(serial)`; else if `device_id` looks like a path
  (`/dev/...`, `COM<n>`) -> scan, if a port with that name has a USB serial `Some(serial)` else `Some("port:<path>")`; already a serial or `port:` id -> `None`; `None`+no label -> `None`.
  Scan failure -> treat as no scan result (never panic, never block long).
