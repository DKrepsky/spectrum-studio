## Work
Implement `SourceDialog` (props in plan section 5; replace the T13 stub body, keep the exported types):
- Chrome: modal over the app (backdrop `rgba(5,8,14,.6)`), 440px, `max-width: calc(100% - 24px)`, `--surface-2`, radius 8, popover shadow, `role="dialog" aria-modal="true" aria-labelledby`; title `Add source` / `Edit source`; focus trap (`useFocusTrap`, no new dependency),
  opens with focus in Name (text selected in edit modes), Escape = Cancel without confirmation, focus returns to `returnFocusTo`. Testids: `add-source-dialog`, `add-source-name`, `add-source-driver`, `add-source-test`, `add-source-test-result`, `add-source-save`, `add-source-cancel`, `edit-source-forget`.
- Fields (design 4.1): Name (trim, 1-60, unique case-insensitive excluding self vs `useSources.list`; errors `Enter a name.`, `At most 60 characters.`, `A source with this name already exists.`; Add mode: blank name is pre-filled with `<label>` after a successful test, never overwrites typed text).
  Driver `<select>` (Add: `dialogDrivers(drivers)`, helper text from design; Edit: same select disabled at 75% opacity with the locked helper). Parameters via `ParamForm` from `driver.connectionParams`, every connection param required in this dialog (plan section 5 rule), prefilled from the entry; file entries: read-only mono `File` field + helper; simulator: note, no fields.
- Test connection (design 4.1/4.2): calls `useSources.testSource(driverId, connection)`; states idle/running/ok/fail with reserved space, `role="status"`/`"alert"`, texts per design 8; editing a parameter resets to idle; closing discards the result. Compare `result.deviceId` with the edited entry's `deviceId` and with `list`:
  same -> `Serial number <serial> (matches this source)`; different and free -> amber `Different device: serial <new>, this source is <old>. Saving binds this source to serial <new>; its name and settings are kept.` (`role="alert"`, Save enabled, `update_source` sends `deviceId: <new>`);
  owned by another record -> `This device is already in Your sources as "<name>".` and Save disabled; `inUse` -> shows the backend message, Save enabled; failure -> `Test failed: <message>` + `You can still save an untested source.`
- Save (design 4.3/4.4): Add and `edit-detected` -> `useSources.addSource(name, {driverId, deviceId: tested serial or the device's id or null, connection, settings empty})`; Edit remembered -> `updateSource(id, {name, deviceId: rebound serial or null(keep), connection})`; a test is never required;
  backend error text shown in an `role="alert"` line above the buttons, dialog stays open. On success `onClose({saved, forgotten:false})` and **nothing connects**.
- Edit-detected: note `New device, not remembered yet. Save remembers it; it does not connect.`, prefilled default name `<device.label>`, port from `device.location`, no Forget. Edit remembered: `Forget` button (danger outlined, left) -> `useSources.forget(id)` then `onClose({saved:null, forgotten:true})`.
- Connected lock (design 4.4): when `isActiveBusy(...)` is true for the edited entry, parameters + driver disabled, Test hidden, the two helper texts (`In use by the active connection. Disconnect to change the port.`, `This source is connected. The name changes now; …`); Save sends the name only (`connection` unchanged).
- Enter in a text field = Save when enabled. Tab order: Name, Driver (skipped when locked), params (skipped when locked), Test connection, Forget, Cancel, Save.
- Styles in `src/styles/sourceDialog.css` (import from the component); no new colours; reduced-motion respected; result box has a fixed min-height so the dialog does not jump.

## Acceptance
`npm run check` green. Handoff lists any deviation from the prototype with a screenshot (`npm run docs:screenshot` or a Vitest-free manual render via the dev server).

## Tests (required, `SourceDialog.test.tsx` with `mockApi`)
Add: empty form, Save disabled until name and port valid, Save without test works (untested note), duplicate name error, name pre-fill after test, Save calls `addSource` with the tested serial and does not call `connect*`.
Edit remembered: prefill, driver locked, rename only, port change untested keeps `deviceId: null`(keep) in the call, port change tested with a different free serial shows the amber note + sends the new `deviceId`, serial owned elsewhere disables Save, failed test message text, in-use message.
Edit detected: note, default name, Save calls `addSource` (not `updateSource`), no Forget. Simulator/file variants (read-only File, no Test). Connected lock variant (params disabled, Test hidden, name-only update).
Forget in dialog calls forget and reports `forgotten: true`. Keyboard: focus lands in Name, Tab order cycles (trap), Escape cancels and returns focus to the provided element, Enter saves. Backend error from `updateSource` stays in the dialog. Accessible names/roles for the test result.
