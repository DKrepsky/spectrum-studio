## Work
1. **Glyphs** (`status.tsx`): replace the text glyphs with a CSS-drawn `<span class="src-dot" data-status="connected|acquiring|connecting|disconnecting|failed|absent|idle" aria-hidden>`; table in design 2.0
   (green filled + 2px halo with `--accent`; red bold cross for failed; gray filled idle; hollow ring absent; blue pulsing connecting/disconnecting; reduced motion = static ring). Idle/absent semantics per design 2.0 rule
   (unprobed kinds never hollow). Same component on rows and on the source button; button has no glyph when no active source.
2. **Layout / fixed widths** (new `src/styles/source.css`, move the existing source rules out of `app.css`, import it where `app.css` is imported): source button `min-width:150px; max-width:280px; flex:0 1 auto`, name ellipsis, no badge/status text;
   popover `width:360px; min-width:280px; max-width:calc(100vw - 16px)`, shifts left to stay inside the window, `max-height:70vh`; row grid `18px minmax(0,1fr) 64px`, min-height 44px, gap 8px, padding 5px 8px; badge element `.src-badge` always 64px, centred,
   `white-space:nowrap`, in column 3 for every row (`USB`, `File`, `Built-in`; the fixed Signal simulator item too); line 2 always rendered (min-height 17px), status text never shrinks, detail (port/path) is mono 11px with ellipsis and `title`;
   actions slot absolutely positioned in column 3 of line 2 (two 26x24 buttons in 54px), `visibility:hidden` until hover/focus-within/keyboard selection, no layout change when shown. Row `title` = name, driver, serial, port/path on separate lines.
   Dimmed (absent) rows: muted name colour, NOT opacity dimming of the status text. Max 6 rows then the Your sources section scrolls.
3. **Rows**: `YourSourceRow` drops the inline-rename mode and the `renaming` state; `✎` button `data-testid="source-edit"` (`aria-label="Edit <name>"`, title `Edit (F2)`) opens the dialog with `{mode:'edit', entry}`; `×` keeps `source-forget` (`Forget <name>`, title `Forget (Delete)`);
   detected rows get only `✎` (`{mode:'edit-detected', device}`). `F2` on a focused row = Edit, `Delete` = Forget, `ArrowRight/Left` into/out of the actions (existing `useMenuKeys`). The rename hint text and `source-rename*` ids disappear.
4. **Add source…**: `FixedItem` `source-add` replaces `source-other` and the `'other'` view; visible only when `dialogDrivers(drivers).length > 0`. It opens `<SourceDialog target={{mode:'add'}} …>`. While the dialog is open the menu is hidden (not unmounted state loss: keep scan stopped);
   `onClose({saved, forgotten})` re-opens the menu, focuses the saved row and highlights it for 3 s (`data-highlight`, reduced motion = outline); `forgotten` re-opens with the existing `Forgot "<name>". Undo` toast (reuse `useSources.forgotten`). Focus returns to the source button on Cancel.
   The inline `SourceForm` stays for detected/file entries that miss a required parameter (unchanged).
5. **Source button**: accessible name `Source: <full name>, <state>`, `title` full name + `Choose source (Ctrl+K)`; `Choose a source` placeholder with the one-time attention outline. Toolbar order unchanged (button, Run, pill, SIMULATED).
6. `Toolbar.tsx`, `NoticeBanner.tsx`, `App.tsx`: only the copy/ids changes needed (no `Other sources`, no `Rename`).
