# T4 `src/ui`: display components (Badge, StatusDot, Banner, BannerRegion, LiveRegion, Section, Table, StatusStrip)

Goal: build the display components, including the F0 status-bar mechanism, with tests, unwired.
Dependencies: T1. Parallel: yes with T2, T3, T5.

Files (all new): `src/ui/Badge/`, `StatusDot/`, `Banner/` (Banner, BannerRegion), `LiveRegion/`, `Section/`, `Table/`, `StatusStrip/`. Props: plan.md section 4; DESIGN.md 3.4, 4.7-4.9, 4.13-4.16, 9.6.
Rules:
- `StatusDot`: port `.src-dot` CSS from `src/styles/source.css` (shapes, animation, reduced-motion halo via `--color-halo-*`); `aria-hidden`; one implementation (E5). Do not delete the old one (T9).
- `Banner`: tones `warning` (tint 12%, F10) / `error`; `urgency` sets `role="alert"` or `role="status"`; dismiss is an `IconButton`-equivalent 24px target with label; message wraps, never truncates. `BannerRegion` is an always-mounted `aria-live="polite"` container (B2).
- `StatusStrip`: renders pinned items always; droppable items sorted by `dropOrder` are removed whole, lowest first, until the content fits; font 11px (F5). Measurement through an injectable `measure` prop (default uses `scrollWidth`/`clientWidth` and a `ResizeObserver`; guard for jsdom where it is undefined). Tests stub `measure` and assert: nothing dropped when it fits; drop order; pinned never dropped; re-evaluates on resize and on items change; empty state renders `empty`.
- `Table`: `.readout-table` look; active row; empty row text; row `onSelect` pointer target only (keyboard id cell is B4, out of scope).
- `Section`: native `details`/`summary`, ring on summary.
Acceptance: `npm run check`; tests for every variant and state above; no consumer changes.
