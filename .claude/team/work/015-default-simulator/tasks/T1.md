- `crates/spectrum-core/src/model/session.rs`: `SessionStatus.launching: bool` (doc: true from
  `AutoConnect::start` until the launch rule has finished; false otherwise); `SessionStatus::new` sets

  `Connected` real source; "no source" states are handled by the existing worker check. Change

  debug log only. A found device whose connect fails does nothing more (no fallback). `on_event` Added:
  replace `has_active_source()` with `!may_replace`-based check (`Acquiring` or a non-simulated

  `AutoConnect::start`: `session.set_launching(true)` before spawning the coordinator;
  `coordinate()` calls `session.set_launching(false)` after `contain("launch", ..)`; if the thread fails
