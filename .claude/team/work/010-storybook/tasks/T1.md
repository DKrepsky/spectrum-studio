# T1: Storybook infrastructure, guards and stories for every `src/ui` component

Single developer task. Parallelism: none (it touches shared config; a split would collide on
`package.json`, `tsconfig.json`, `eslint.config.js`). Dependencies: none. Read `plan.md` and
`docs/adr/0016-storybook-component-catalogue.md` first; the ADR is a draft, adjust it if reality
differs and note it.

## Goal

Issue #36 acceptance criteria all hold, with `npm run check` failing on a missing stories file or a
story that throws.

## Steps (in this order; commit-sized checkpoints)

1. **Infra spike**: `npm i -D storybook@^10.6.7 @storybook/react-vite@^10.6.7`. Create
   `.storybook/main.ts` (stories glob `../src/**/*.stories.@(ts|tsx)`, framework `@storybook/react-vite`,
   `core.disableTelemetry`, `viteFinal` removing the pinned Tauri `server` settings, no addons) and
   `.storybook/preview.tsx` + `preview.css` per plan. Add one Button story. Run `npm run storybook`
   and `npm run build-storybook`. If Vite 8/TS 6 is incompatible and it cannot be fixed in config,
   stop and send a `question` to staff-engineer.
2. **Config hygiene**: scripts `storybook`, `build-storybook`; `.gitignore` `/storybook-static`;
   `.prettierignore` and eslint `ignores` `storybook-static`; tsconfig `include` adds `.storybook`;
   eslint block for `.storybook/main.ts` if needed. `npm run lint`, `typecheck`, `format:check`
   pass.
3. **Guards**: `src/ui/stories.test.tsx` (coverage guard, glob guard, render-every-story test, with
   `play` run) and the storybook-not-in-app guard, each with a self-check, as in the plan.
4. **Stories**: one `<Name>.stories.tsx` for every folder in `src/ui/` that has an `index.ts`, with a
   story per state in the component's DESIGN.md section 4 entry (default, variants, sizes, focus,
   unavailable, busy, error, long text, open overlays). Sample data are literals; no formatting calls;
   no imports forbidden by ADR 0015. No hex/px colour literals (use tokens).
5. **Tokens page**: `src/styles/Tokens.stories.tsx` per plan.
6. **Docs**: lines in `src/ui/README.md`, `DESIGN.md` 10.2/10.3 (two short lines, flag in handoff),
   `docs/development.md`, `docs/testing.md`, ADR status to accepted if the PM agrees.

## Acceptance

- `npm run storybook` lists every `src/ui` component plus the tokens page; each state has a story.
- `npm run build-storybook` succeeds with no errors; `storybook-static/` is git-ignored.
- `npm run build` then `grep -ril storybook dist` finds nothing; `npm run check` is green.
- Mutation proofs (record the output in the handoff): removing a stories file fails the coverage
  guard naming the folder; a story that throws fails the render test; `import 'storybook'` added to
  `src/main.tsx` fails the boundary guard.
- Screenshot comparison (Read tool) of at least Button, Dialog, Table and the tokens page in
  Storybook against the app: colours, fonts, spacing match. Save to
  `.claude/team/work/010-storybook/screenshots/`.
- No new dependency beyond the two named; no changes to app code under `src/components`, `src/state`,
  `src/ipc`, Rust, or `vite.config.ts`. Changes to component files only if a story exposes a real bug
  (then report it, do not hide it).

## Required tests

`src/ui/stories.test.tsx` as above (Vitest, jsdom); the whole existing suite must stay green.
