# 014 T1: `ParamPlacement` on `ParamSpec`, SA430 marks its rows, bindings

Goal: a driver can say which runtime settings belong in the Measurement group. See ADR 0018.

Files:
- `crates/spectrum-core/src/model/params.rs`: add
  `enum ParamPlacement { Source (default), Measurement }` (`#[serde(rename_all = "camelCase")]`,
  `ts(export)` like its neighbours, `Default` = `Source`), field `pub placement: ParamPlacement` on
  `ParamSpec` with `#[serde(default)]`, and builder `pub fn in_measurement(mut self) -> Self`. The
  constructors (`number`, `boolean`, `choice`) set `Source`. Export it from `model/mod.rs` and the
  crate root as the other param types are.
- `crates/spectrum-driver-sa430/src/lib.rs`: `runtime_params()` marks `stepKhz` and `refLevelDbm` with
  `.in_measurement()`; keep order, labels, help text and ranges unchanged. Add `placement` to the
  `connection_params()` struct literal (`Source`).
- Other `ParamSpec { .. }` literals that must gain the field: `crates/spectrum-core/tests/probe.rs`,
  `tests/session.rs`, `tests/autoconnect.rs`, `tests/remember.rs`, `src/store.rs` (tests),
  `crates/spectrum-driver-sa430/tests/*` if any (find with `grep -rn "group: None"`).
- `docs/sources.md`: document `placement` in the parameter section (what it means; measurement rows
  appear after Center and Span in driver order; everything else is in Source settings; FFT size and
  Window are not driver params).
- Run `npm run bindings`; commit `src/bindings/ParamSpec.ts` and `src/bindings/ParamPlacement.ts`.

Acceptance:
- `ParamSpec` JSON without `placement` deserialises with `Source`; with `"placement":"measurement"`
  round-trips.
- The SA430's `Capabilities.params` is `[stepKhz, refLevelDbm]`, both `Measurement`.
- Nothing else changes behaviour: `resolve_params`, `check_partial`, apply paths untouched.

Tests (required):
- `params.rs` unit tests: default placement is `Source`; `in_measurement()` sets it; serde round trip and
  the missing-key default.
- SA430 crate: a test on `runtime_params()` (id order, placement, unit `kHz`, 10-500 range).
- `npm run check` passes (bindings regenerated and committed).

Dependencies: none. Parallel: yes, with T2 (disjoint files). Blocks T3 (needs the generated type).
